# MedFlow — Требования к системе

## 1. Роли пользователей

### 1.1 Администратор
- Управление справочниками (специализации, услуги)
- Управление пользователями и ролями
- Просмотр отчётов по клинике
- Управление расписанием всех врачей

### 1.2 Регистратор
- Регистрация новых пациентов
- Запись пациентов на приём к врачу
- Отмена и перенос записей
- Просмотр расписания врачей

### 1.3 Врач
- Просмотр списка своих пациентов
- Ведение медицинской карты пациента (диагнозы, назначения)
- Выписка рецептов
- Просмотр своего расписания
- Отмена приёма по своей инициативе

### 1.4 Пациент
- Просмотр своей медкарты
- Запись на приём к врачу
- Отмена своей записи
- Просмотр истории посещений

## 2. Сущности системы

| Сущность           | Описание                                    | Связи                                   |
|--------------------|---------------------------------------------|-----------------------------------------|
| Patient            | Пациент клиники                             | → Appointments, MedicalRecords          |
| Doctor             | Врач-специалист                             | → Specializations (M:N), Appointments   |
| Specialization     | Специализация (терапия, хирургия и т.д.)    | → Doctors (M:N)                         |
| Appointment        | Запись на приём                             | → Patient, Doctor, Service              |
| MedicalRecord      | Запись в медкарте (диагноз, анамнез)        | → Patient, Doctor                       |
| Prescription       | Рецепт / назначение                         | → MedicalRecord                         |
| Service            | Медицинская услуга (с ценой)                | → Appointments                          |
| User               | Учётная запись (ASP.NET Core Identity)      | → Patient | Doctor (1:1, nullable)    |

## 4. Ограничения

- ФЗ-152: персональные данные хранятся с соблюдением требований
- Врачебная тайна: врач видит только своих пациентов
- Аудит: все изменения медкарты логируются
- Soft delete: записи не удаляются физически
